## 四、不具备的数据（6 类）

| 缺什么 | 现状 | 后果 |
|---|---|---|
| **估值**（PE/PB/市值/换手） | 源库有 `fact.market_value` **6,519 万行**（pe_ttm、pb、total_mv、float_mv…），**未接入** | 低估值/市值分层类因子无法使用 |
| **财务指标**（PIT） | 源库有 `fact.financial_indicator` **899 万行**，`available_at` 100% 齐全，**未接入** | ROE/营收增速等基本面因子无法使用 |
| **板块与概念** | 空表 | 板块轮动、概念热点类策略无法使用 |
| **指数历史成分** | 无 | 「上证50/沪深300/中证500/中证1000/中证A500成分」**5 个选股域被禁用**（平台明确拒绝用当前成分回填历史） |
| **全市场分钟线** | 仅 155 只、且只到 2026-07-17 | 「14:45 执行」积木块不可用（需全市场 14:45 分钟价） |
| **基金 / ETF 行情** | 0 只 | 无法做 ETF 轮动、LOF 套利 |

### 由此不可用的积木块（共 7 个，平台已自动置灰）

| 积木块 | 原因 |
|---|---|
| 上证50成分 / 沪深300成分 / 中证500成分 / 中证1000成分 / 中证A500成分 | 缺历史成分变更表 |
| 14:45 执行 | 缺全市场 14:45 分钟价 |
| 本地已保存策略 | V1 不执行未白名单审核的任意 Python 策略（设计如此） |

**其余 8 个选股域可用**：沪深京全市场、沪深、沪、深、京、主板、科创板、创业板（按交易所 + 代码前缀划分，不依赖成分表）。
**90 个积木块里 83 个可用**，且全部从 `daily_bar` 实时计算，不依赖预计算特征。

## 五、如果要补数据

源库已经把估值与财务准备好了，只是桥接层没映射。补的时候要做两件事：

1. `build_local_dataset.py` 里增加两张表的映射（长表 → 后端期望的宽表或长表，需先确认积木块的读取口径）；
2. 体积会涨：`market_value` 6,519 万行、`financial_indicator` 899 万行，粗估 **+0.8 ~ 1.2 GiB**（未实测，需先建再量）。

补完之后，「低估值 + 反转」这类策略才具备测试条件——而目前的标准多因子预设只用了价量，所以它能在 0.7 GiB 的最小包上跑通。
