# 量构 QuantWeave 回测实验室

## 节点策略工作站

乐高策略首页采用类似扣子工作流的节点画布。左侧模块库可以随时加入注册模块，中央画布支持拖动、缩放、小地图、分支、汇合和端口连线，右侧面板编辑选中模块的启停状态、AND/OR 与全部参数。

画布连线会保存到流水线的 `workflow` 字段，并由 `lego_workflow.compile_workflow` 编译成后端执行顺序。运行前必须满足：

- 一个股票池入口和一个成交出口；
- 所有启用节点均从入口连通到出口；
- 不存在环路、自连线、重复连线或逆阶段连线；
- 分支和汇合后的模块仍满足后端点时数据与 A 股撮合校验。

拖动节点只改变布局，不改变策略哈希。保存和加载策略时，模块参数、节点坐标和连线会一起恢复。

## 已安装架构

- **VeighNa 4.4.0 + PortfolioStrategy 1.3.0**：主研究框架和后续组合/Alpha 扩展。
- **Backtrader 1.9.78.123**：当前透明事件回放内核，承载网页上的教学策略和 A 股撮合约束。
- **QuantStats 0.0.81**：绩效指标与可下载 HTML 报告。
- **Streamlit 1.59.2**：本地交互面板。
- **DuckDB**：直接只读 `data/market_data.duckdb`，不复制本地日线数据库。
- **PyTDX**：回填 14:30–15:00 的 1/5/15 分钟线到独立 `data/minute_bars.duckdb`。
- **Polars + Alphalens + LightGBM + Scikit-learn**：后续 Alpha158、因子分析和滚动机器学习。

VeighNa 本地适配器在 `veighna_adapter.py`，已把本地日线和分钟缓存转换成标准 `BarData`。当前网页回放仍使用更容易审计的 Backtrader 撮合层；未来策略迁入 VeighNa PortfolioStrategy 时，数据接口不需要重写。

## 14:45 时间语义

系统明确提供三种模式：

1. **次日开盘**：信号日收盘后形成信号，下一交易日开盘成交，适合全历史日线。
2. **次日 14:45**：信号日收盘后形成信号，下一交易日使用缓存的 14:45 分钟价格成交；缺分钟数据的日期直接排除，不用日开盘价补缺。
3. **同日 14:45 冻结信号**：只用于尾盘强度案例。特征只读取 14:30–14:45 已完成数据，订单在下一根分钟 K 线开盘成交。通达信 5 分钟柱按结束时点标记，因此通常对应 14:50 标记柱的开盘，即约 14:46。

第三种模式不会使用 14:45 柱开盘价成交，因为那会把已经走过的价格倒填给刚刚生成的信号。

## 全市场股票池

“沪深京全市场”和“沪深全市场”不会把数千只股票同时塞进 Backtrader。DuckDB 会先对完整股票池向量化计算信号和横截面排名，再把每日 Top N 候选及已有持仓交给 A 股事件撮合层。当前全市场模式支持买入持有、双均线、RSI、动量轮动和海龟突破，固定使用“当日收盘信号、次日开盘成交”。

数据库尾部若仍在同步，系统会自动剔除股票覆盖数低于此前 20 个交易日中位数 80% 的日期，避免少量已更新股票被误当成完整市场。结果页会分别显示实际参与股票数、候选股票数、候选记录数和完整交易日数。

## 乐高策略工厂

回测页默认进入“乐高策略”。股票池、硬筛、策略初选、多因子、横截面标准化、风险惩罚、每日排名、组合仓位和 A 股撮合均为独立积木，可新增、删除、启停、上下移动并保存整套配置。筛选积木支持同组 AND/OR；多因子坚持“一项因子一块”，每项分别设置权重、方向和 `robust_sigmoid`/百分位变换。

当前公开节点库只展示比赛版可以真实运行的通用积木，包括 ST/可交易/涨停/上市天数/成交额过滤，动量、双均线、RSI、海龟，趋势/动量/波动/量价/流动性/回撤因子，稳健横截面标准化，以及波动/回撤/流动性惩罚。未实现或缺少 point-in-time 数据的模块不会进入公开目录，也不会生成替代数据或假回测。

每次运行会保存：

- 逐层数据沙漏及淘汰原因；
- 每日 Top K、原始因子、标准分、权重贡献和风险扣分；
- 目标组合、完整成交、单笔盈亏、权益和回撤；
- 流水线 JSON 与 `pipeline_hash`，用于复核参数是否完全相同。

## A 股撮合约束

- 100 股整手；
- 日线信号次日成交，同日尾盘信号下一根分钟 K 成交；
- 买入后最早下一交易日卖出，满足 T+1；
- 名称含 ST 的证券自动剔除；
- 主板 10%、创业板/科创板 20%、北交所 30% 涨跌停阻断；
- 零成交量视为停牌；
- 单根 K 线最大成交量参与率默认 10%；
- 佣金、最低 5 元、过户费、卖出印花税和滑点均进入权益；
- 成交记录包含股票名称、代码、方向、费用、单笔盈亏和单笔收益率。

## 分钟数据

默认 5 只示例股已经回填到 2024 年 6/7 月至 2026-07-17 的尾盘五分钟窗口。手工扩展：

```bash
npm run minutes:fetch -- \
  --codes 600519,000858,300750 \
  --start 2024-07-01 \
  --end 2026-07-17 \
  --frequency 5m
```

公共通达信节点实测大致保留：1 分钟约近 4 个月，5/15 分钟约近 2 年。十年精确分钟历史必须接 QMT 历史权限或持牌商业数据源；系统不会把日线伪装成 14:45 成交价。

## 教学策略

- 等权买入持有；
- 双均线趋势；
- RSI 均值回归；
- 截面动量轮动；
- 海龟/Donchian 突破；
- 14:45 尾盘强度轮动；
- 随机森林滚动训练案例。

机器学习案例使用时间顺序滚动训练，不随机打乱样本。它可能明显亏损，这正是教学内容的一部分：复杂模型不等于有效策略。
